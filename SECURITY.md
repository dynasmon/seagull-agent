# Security Policy

## Reporting

Use GitHub's private vulnerability reporting for
`dynasmon/seagull-agent`. Include the affected version, deployment profile,
reproduction steps, impact, and any proposed mitigation.

Do not open a public issue for an undisclosed vulnerability. Do not attach real
enrollment tokens, credentials, certificates with private material, private
keys, agent identity files, or production configuration.

## Supported versions

Security fixes are issued for the latest stable release. Compatibility metadata
published with each release defines the supported platform and agent protocol
window. Operators should verify release checksums, keyless signatures, and
GitHub build provenance before deployment.

## Response

Reports are triaged for reproducibility, affected versions, exploitability, and
fleet impact. A coordinated fix may include a patched agent release, updated
compatibility policy, mitigation guidance, and a security advisory.
